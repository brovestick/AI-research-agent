# 中际旭创：投资决策备忘录

**股票代码**: 300308.SZ | **行业**: 光模块 | **生成时间**: 2026年3月12日

---

## 一、核心观点摘要

### 看多逻辑

- **AI算力需求持续超预期**：北美四大云厂商2026年资本开支指引大幅上调（谷歌+100%至1800亿美元、亚马逊+50%至2000亿美元、Meta+73%至1250亿美元），算力军备竞赛延续
- **产品结构升级驱动毛利率提升**：1.6T光模块加速放量，硅光渗透率持续提升（800G硅光占比35-50%，1.6T硅光占比更高），EML向硅光切换带来成本优势20-30%
- **龙头地位稳固**：2024年LightCounting全球光模块厂商排名第一，800G/1.6T出货量全球领先，客户覆盖北美四大CSP
- **Scale-up市场布局**：公司积极布局柜内光连接产品，预计2027年开始起量，打造第二增长曲线
- **H股上市拓宽融资渠道**：筹备港股上市，有望成为中美AI硬件估值体系的重要桥梁

### 核心风险

- **CPO技术替代风险**：NVIDIA宣布2026年规模部署CPO，若CPO在2027年前实现大规模应用，将对可插拔光模块形成替代威胁
- **客户集中度风险**：北美四大云厂商收入占比超70%，单一客户依赖度高，CSP资本开支波动将直接影响公司业绩
- **供应链瓶颈**：光芯片（EML、CW激光器等）供应紧张，部分物料出现阶段性提产瓶颈，制约产能释放
- **关税政策不确定性**：中美贸易摩擦背景下，关税政策变化可能影响海外客户订单和毛利率
- **汇兑损失**：公司海外收入占比高，人民币汇率波动导致财务费用上升

## 二、深度分析与待验证问题

### 议题一：CPO替代与技术路线演进

**背景：**
NVIDIA宣布2026年规模部署CPO，引发市场对可插拔光模块被替代的担忧。Morgan Stanley研报采用概率加权估值法，给予CPO冲击30%权重（bull case延迟至2028年后）、50%权重（2027-2028年大规模应用）、20%权重（2026年下半年即开始冲击）。公司已布局NPO（Near-Packaged Optics）技术，并在多个CSP客户进行验证，预计2027年贡献收入。NPO被视为对抗CPO替代风险的关键护城河。从技术路线看，Scale-out场景CSP不倾向部署CPO，Scale-up场景CPO量产最早在2H28。

**提问：**
Q1: 公司对CPO大规模商业化应用时间节点的判断是什么？Scale-out和Scale-up场景是否会有不同的替代节奏？;
Q2: NPO产品目前与哪些CSP客户在验证中？验证进展如何？预计何时能实现商业化出货？;
Q3: 如果CPO在2027年开始规模应用，公司在可插拔光模块之外还有哪些技术储备和产品布局？;

---

### 议题二：1.6T光模块放量节奏与毛利率提升空间

**背景：**
公司2025年营收382.4亿元（+60.25%），归母净利润107.99亿元（+108.81%），Q4单季净利润36.67亿元创历史新高。Citi预测公司2026年400G/800G/1.6T出货量分别为180万/1500万/1000万只，2027年分别为99万/2000万/2500万只。硅光方案BOM成本低20-30%、功耗低40%，1.6T硅光渗透率高于800G。券商预测2026年收入增速40-155%（差异较大），毛利率预测42-49%。Goldman Sachs预测2026-2028年毛利率分别为45.3%/45.4%/47.9%。

**提问：**
Q1: 1.6T光模块目前出货量占比约多少？预计2026年全年1.6T出货量占比能达到什么水平？;
Q2: 800G和1.6T产品中硅光方案的占比分别是多少？硅光方案相比EML方案的毛利率优势有多少个百分点？;
Q3: 2026年全年毛利率指引是多少？产品结构升级（1.6T+硅光）对毛利率的提升作用如何量化？;

### 议题三：供应链保障与产能扩张

**背景：**
光芯片供应持续紧张，Lumentum计划未来几个季度产能扩张40%，Tower Semiconductor亦在扩产。公司25Q4业绩增长受部分物料阶段性提产瓶颈制约。野村研报指出，在供应链紧张的市场环境下，公司的领先市场地位有助于获取光芯片等关键零部件。产业链调研显示，公司物料准备情况超预期，一线龙头备货情况好于二三线公司。泰国工厂产能持续爬坡中。

**提问：**
Q1: 公司目前EML芯片、CW激光器等核心物料的锁定情况如何？2026年物料供应能否支撑收入翻倍增长的目标？;
Q2: 泰国工厂产能爬坡进展如何？2026年底预计能达到什么产能水平？产能分布（国内vs海外）策略是什么？;
Q3: 硅光方案自研PIC的良率和产能情况如何？是否能有效缓解EML芯片供应紧张的压力？;

### 议题四：客户集中度与订单可见性

**背景：**
公司收入高度集中于北美四大云厂商（Google、Meta、Microsoft、Amazon），占比超70%。2026年北美云厂商资本开支指引大幅上调，但DeepSeek效应下算力性价比革命可能导致CSP资本开支缩减预期。近期社交媒体流传"CSP绕过光模块厂商直接向上游光芯片厂下单"的传言，公司已辟谣表示商业模式未改变。招商研报指出，谷歌等CSP对2027年给出了较高采购需求指引。

**提问：**
