# 光模块技术分歧点：买方视角分析报告

**2026年3月12日 | 核心结论前置：CPO短期冲击被过度定价，可插拔主线地位2年内无虞；真正的分歧在于NPO能否成为"护城河再造"的窗口期，以及EML vs. 硅光的份额切换速度。**

## 二、技术演进节奏：买方明确立场

### 2026年：可插拔主线不变，LPO/1.6T是最硬的增量

- 1.6T光模块**已进入量产放量周期**，2025-2027E出货量CAGR 63%（BofA数据）
- EML芯片供应持续短缺（Lumentum FY26Q1已验证），硅光渗透加速是**被动倒逼**而非主动替换
- 800G以上光模块市场空间：2026/27/28年预计达166/248/355亿美元（中泰证券）
- 硅光市场份额：2023年34% → 2029年预计52%（LightCounting），800G硅光当前市占率35%-50%
- LPO在ByteDance等头部CSP已放量，800G LPO商业化成熟；META亦在小规模部署800G LPO

### 2027-2028年：NPO是最重要的边际变量

- NVIDIA的"CPO"产品**本质上是NPO架构**（光引擎可拆卸），并非真正CPO
- NPO光引擎距ASIC约1-5cm（可达150mm），CPO约0-50mm；NPO制造难度远低于CPO
- 功耗对比（1.6T连接）：Retimed Optics 30W → LPO 10-12W → NPO 5-8W → CPO 2.5W → 铜缆 0W
- 中际旭创已与多个CSP客户验证open-socket NPO方案，**预计2027年贡献收入**
- Lightcounting预测：至2030年LPO出货量仍高于CPO

### 2028年以后：CPO才是真正颠覆性节点

- Bernstein明确：scale-up CPO量产最早2H28
- Broadcom路线图：铜缆功耗优势到2028年前仍优于传统CPO，CPO真正功耗优势在2028-29年兑现
- 3.2T插拔模块预计2028年进入量产，届时pluggable还有一代产品窗口

## 三、四大关键分歧的投资影响排序

### 【第一优先级】CPO替代时间节点 — 影响最大，当前市场定价错误最显著

**核心矛盾**：市场在2026年初将CPO替代风险定价到可插拔估值中，导致估值"非理性分化"。但：

- Scale-out（占数据中心网络功耗仅5%）：CSP明确**不倾向**大规模部署CPO
- Scale-up：供应链验证未完成，真正量产最早2H28
- CPO当前ASP比可插拔方案**贵约10%**（Bernstein测算），早期成本并无优势
- **买方立场**：当前CPO恐慌是买入可插拔龙头的窗口，而非离场信号。2026-2027年可插拔/LPO/NPO的业绩增长将自然纠偏这一预期差。

### 【第二优先级】EML vs. 硅光渗透速度 — 影响产业链价值分配

**方向无争议，速度有分歧**：

- 硅光BOM成本低20-30%，功耗低约40%，体积缩小约30%，量产潜力大
- 争议核心：EML良率恢复速度 vs. 硅光PIC良率提升速度
- 硅光调制器带宽上限（67GHz）在400G单通道时面临瓶颈，需引入TFLN才能覆盖3.2T需求
- **买方立场**：拥有自研硅光PIC能力的厂商（中际旭创、新易盛）在1.6T节点享有明确定价权，这是当前最确定的alpha因子。EML依赖厂商（光迅科技等）面临结构性压力。

### 【第三优先级】NPO商业化路径 — 潜在的alpha来源

**市场认知不足**：多数研报将NPO视为"过渡方案"而低估其战略价值。

- NPO性能接近CPO（Morgan Stanley明确），但制造复杂度大幅低于CPO
- NPO可维护性（Socket-based）更易被CSP接受，open ecosystem优势明显
- 传统光模块厂商**能够参与**NPO生态（不像CPO被半导体厂商主导），是重要的价值保留机制
- **买方立场**：NPO是传统光模块龙头对抗CPO颠覆风险的"护城河再造"窗口，2027年收入贡献是关键催化剂。

### 【第四优先级】TFLN调制器商业化 — 3.2T节点的远期期权

- TFLN 3dB带宽108GHz，显著优于纯硅光调制器67GHz
- 硅光市场份额预计从2023年34%升至2029年52%，TFLN份额同步提升
- 硅光模块销售额：2023年14亿美元 → 2029年预计103亿美元（CAGR 45%，Yole数据）
- **买方立场**：TFLN是2027年以后的主题，当前更多是概念溢价，不建议在此阶段为TFLN单独付估值溢价。

## 五、风险提示

**主要下行风险**：

1. GTC（3月16-19日）或OFC（3月15-19日）若NVIDIA/Broadcom发布超预期CPO量产时间表，可能短期压制可插拔估值（近期催化剂风险窗口）
2. 1.6T量产良率若不及预期，将推迟整个技术升级周期
3. 硅光PIC国产化进度若慢于预期，头部厂商利润率改善逻辑受阻
4. CSP资本开支缩减（DeepSeek效应下算力性价比革命）可能导致需求绝对量低于预期

**主要上行风险**：

1. EML芯片持续短缺加速硅光渗透，1.6T硅光模块提前成为绝对主流
2. NPO被多个CSP同步验证通过，2027年出货量超预期
3. AI集群规模从万卡向十万卡演进，scale-up互联需求引爆提前

---

**核心投资结论**：当前技术分歧的本质是"时间表之争"而非"方向之争"——可插拔被替代是确定趋势，但2026-2027年的现金流和利润仍由可插拔（尤其1.6T硅光）贡献；CPO冲击股价的节点在2H28前不会真正兑现。持有拥有自研硅光PIC、同时布局NPO的龙头，是当前最优风险收益比的选择。---
