## 核心内容

报告聚焦基于DeepSeek大模型的周报月报全自动生成框架，旨在解决通用大语言模型在生成个性化投研报告时存在的结构化数据获取不足、新闻搜索范围不精确、定制化图表生成困难等问题。报告提出通过高质量数据、新闻、观点为基础，结合提示词工程和Python排版模块，实现信息来源可控的个性化定期报告自动化生成。

- 图表输出

针对不同任务设计差异化处理流程，如数据点评需结构化数据提取与提示词设计，新闻点评则通过RAG技术从海量新闻中检索信息。

- 可靠财经新闻（财联社等）
- 研报观点
- 结合大模型逻辑推理与RAG技术，确保内容可靠性与来源可控

### 3. 自动化排版
通过Python调用Word/PPT排版模块，支持：
- 文本样式设置
- 表格插入
- 图表导出
- 模板套用

实现全流程自动化，提升办公效率。

## 主要结论

1. **通用模型局限性**：通用大语言模型因数据获取、新闻检索、图表生成等问题，难以满足个性化投研报告需求。

2. **方案有效性**：基于DeepSeek+Python的自动化框架可输出信息来源可控、格式规范的定期报告，显著提升撰写效率，适用于内容结构固定的制式报告（如周报、月报）。

3. **局限性**：需为不同系列报告单独组装代码模块，观点输出依赖研报素材，无法完全自主生成原创观点。
