# 调研问题检索方案

本文档定义了生成上市公司调研问题清单的6维检索框架。

## 工具说明

| 原 Alpha Engine 工具 | Claude Code 替代 |
|---|---|
| `search_finance_reports` | `web_search` + `web_fetch` |
| `query_finance_data` | `fetch_financials.py`（akshare） |
| `ask_web_question`（回退） | `web_search` + `web_fetch` |

**原参数转换规则：**
- `date_range`：转为查询语句中的时间修饰词
- `recall_num`：不适用，改为对最相关的 2-3 个页面执行 `web_fetch` 深入读取

---

## 检索规则

1. 每个维度使用 `web_search` 检索，对最相关结果执行 `web_fetch` 深入读取
2. 查询格式：`{公司名称} + 维度查询词`
3. 财务数据优先使用 `fetch_financials.py` 获取结构化数据，不足时补充 `web_search`
4. 若初始检索数据不足，调整关键词后再次检索

---

## 六维检索计划

### 维度1：短期热点话题

**目的**：收集公司短期（3个月内）的市场关注事件

**查询语句：**
```
{公司名} 近三个月重大事件 股价异动 热点话题 市场关注
```

- 时间限定：近3个月
- 重点来源：财经新闻、公司公告、券商点评

**分析要点：**
- 近3个月的具体事件
- 对市场情绪的影响
- 对短期业绩的潜在影响

---

### 维度2：经营情况探讨

**目的**：深入了解公司业务运营状况

**查询语句：**
```
{公司名} 经营情况 业务增长 渠道策略 产品创新 客户运营
```

- 时间限定：近半年
- 重点来源：券商研报、公司公告、业绩说明会

**分析要点：**
- 业务增长驱动力
- 渠道策略
- 产品创新
- 客户运营

---

### 维度3：市场竞争环境

**目的**：分析公司在行业中的竞争地位

**查询语句：**
```
{公司名} 市场竞争格局 行业地位 竞争对手 差异化 定价权 市场份额
```

- 时间限定：近半年
- 重点来源：券商研报、行业报告

**分析要点：**
- 行业定位
- 与竞争对手的差异化
- 定价权
- 市场份额变化

---

### 维度4：财务指标质量

**目的**：评估公司财务健康状况

**查询语句（两步）：**

步骤1 — 运行辅助脚本获取结构化数据：
```bash
python fetch_financials.py {股票代码}
```

步骤2 — 补充搜索：
```
{公司名} 财务指标分析 盈利能力 现金流 资本结构 营运效率 异常点
```

- 时间限定：近半年
- 重点来源：财报、券商研报

**分析要点：**
- 盈利能力
- 现金流健康度
- 资本结构
- 营运效率
- 异常点或风险信号

---

### 维度5：资本市场动作

**目的**：跟踪公司资本运作活动

**查询语句：**
```
{公司名} 股权融资 债权融资 并购重组 股票回购 分红 股权激励 资产证券化
```

- 时间限定：近半年
- 重点来源：公司公告、财经新闻

**分析要点：**
- 股权/债权融资
- 并购重组
- 股票回购
- 分红政策
- 资本配置策略

---

### 维度6：市场预期变化

**目的**：了解市场对公司前景的预期

**查询语句：**
```
{公司名} 券商盈利预测变化 目标价调整 业绩超预期 分析师分歧 评级变动
```

- 时间限定：近半年
- 重点来源：券商研报、Wind/同花顺资讯

**分析要点：**
- 分析师预测变化
- 市场共识与分歧
- 业绩超预期/不及预期
- 指引与预期的对比

---

## 执行说明

1. **顺序执行**：按维度1→6依次检索，每完成一个维度立即提取关键信息点
2. **回退策略**：若某维度 `web_search` 数据不足，换关键词重试一次
3. **中间产物**：每个维度完成后，草拟该维度的潜在调研问题，供最终整合使用
4. **财务数据**：维度4优先使用 `fetch_financials.py`，补充 `web_search` 覆盖定性分析
