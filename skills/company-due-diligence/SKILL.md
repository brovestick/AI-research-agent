# Company Due Diligence — 入口

## 准备工作

读取以下2个文件，了解完整执行规则：
1. `retrieval_strategy.md` — 6维检索框架与各维度查询语句
2. `report_requirements.md` — 角色定义、工作流程与报告格式要求

---

## 执行流程（串行）

### 阶段1：6维资料检索

按 `retrieval_strategy.md` 的顺序，依次完成6个维度的检索：

- **维度1** 短期热点话题（近3个月）
- **维度2** 经营情况（近半年）
- **维度3** 市场竞争环境（近半年）
- **维度4** 财务指标质量（先运行 `fetch_financials.py`，再补充搜索）
- **维度5** 资本市场动作（近半年）
- **维度6** 市场预期变化（近半年）

每个维度完成后，草拟该维度的潜在调研问题，供下一阶段整合使用。

### 阶段2：撰写调研问题清单

资料检索完成后，读取 `report_requirements.md`，严格按照其中的工作流程（第一步→第四步）和报告格式生成最终输出。

---

## 辅助脚本

`fetch_financials.py`（需与本文件在同一目录，维度4调用）：
```bash
python fetch_financials.py {股票代码}
```
