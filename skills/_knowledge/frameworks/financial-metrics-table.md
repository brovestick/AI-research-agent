## 标准财务指标表格

### 合并报表健康度表格（模块 03 定义）

近三年趋势，趋势列使用箭头符号（↑上升 / → 平稳 / ↓下降）：

| 指标 | {year-2}年 | {year-1}年 | {year}年 | 趋势 | 说明 |
|------|-----------|-----------|---------|------|------|
| 营业收入（亿元） | | | | | |
| 营收增速（%） | | | | | |
| 毛利率（%） | | | | | |
| 净利率（%） | | | | | |
| 归母净利润（亿元） | | | | | |
| 净现比（经营现金流/归母净利润） | | | | | |
| 存货周转天数 | | | | | |
| 应收账款周转天数 | | | | | |
| 应付账款周转天数 | | | | | |
| 现金周转周期（存货+应收-应付） | | | | | |
| 资产负债率（%） | | | | | |
| ROE（%） | | | | | |

表格后附简短文字说明，重点标注异常指标。

### 预测表格（模块 04 沿用）

未来三年预测复用同一表头体系：

| 指标 | {year+1}E | {year+2}E | {year+3}E |
|------|----------|----------|----------|
| 营业收入（亿元） | | | |
| 毛利（亿元） | | | |
| 归母净利润（亿元） | | | |
| EPS（元，基于当前股本） | | | |
| 对应 PE（基于当前股价） | | | |

### 数据要求

- 数据须具体（写明年份和数值）
- 不确定的数据标注"待核实"
- 不要编造数字
- 无法从已有数据直接获取的指标（如净现比、周转天数），可联网搜索补充
