## 增速假设因果链

核心原则：每一条增速假设都必须展示完整的逻辑链条——从可验证的前提出发，经过明确的传导机制，推导出结论。禁止直接给出增速数字而不附因果链。

### A. 原子假设分解

把"营收增速 X%"拆成可独立验证的原子假设，直到每条假设都能被单一数据源验证或证伪。

| 字段 | 说明 |
|------|------|
| 假设编号 | H1, H2, H3... |
| 假设内容 | 一句话描述，尽量量化 |
| 类型 | FACT（已发生/已公布）/ ASSUMPTION（核心假设，须验证）/ PREDICTION（由前两类推导得出） |
| 置信度 | 高 / 中 / 低 |
| 数据来源 | 公告、财报、行业数据、券商预测等，标注具体出处 |

拆解维度参考：产能/产量、产能利用率、单价/ASP、市场份额、下游需求量、客户结构变化、新产品放量节奏。

### B. 因果链标注格式

每条推导须按以下格式写明传导机制，不能只说"A 导致 B"：

```
H1 [前提假设] →【传导机制 | 强度 | 时滞】→ H3 [结论假设]
```

**强度分档：**

| 等级 | 含义 | 示例 |
|------|------|------|
| 强 | 行业公认规律，历史反复验证 | 产能投产 → 固定成本摊薄 → 毛利率提升 |
| 中 | 有数据支撑但存在调节变量 | 下游需求增长 → 公司订单增长（受市占率变动影响） |
| 弱 | 逻辑推测，尚无充分数据验证 | 技术迭代加速 → 客户更换供应商意愿提升 |

**时滞标注：** 传导机制的生效时间（如"1-2 个季度"、"当年"、"次年"），帮助判断假设兑现的时间窗口。

### C. 偏误自检清单

每条因果链完成后，逐项检查以下 8 类偏误：

| 编号 | 偏误类型 | 自检问题 |
|------|---------|---------|
| B1 | 相关不等于因果 | 这两个变量的历史相关性，是否存在第三变量或反向因果？ |
| B2 | 锚定效应 | 增速假设是否只是锚定了历史增速或券商目标价在做外推？ |
| B3 | 幸存者偏差 | 行业增速数据是否只统计了存活企业，遗漏了退出者？ |
| B4 | 叙事谬误 | 这条逻辑链是否把随机事件编成了必然的故事？ |
| B5 | 反向因果 | 是"基本面好→股价涨"还是"股价涨→解读为基本面好"？ |
| B6 | 选择性偏差 | 是否只引用了支持结论的数据，忽视了反面证据？ |
| B7 | 生态谬误 | 行业整体增速能否直接映射到个股增速？公司的份额变化方向是什么？ |
| B8 | 确认偏误 | 搜索信息时是在寻找验证还是在寻找反驳？ |

不要求每条链条都通过全部 8 项——发现命中的偏误时，说明如何缓解或接受该风险。

### D. 敏感度标注

在因果链中标注关键变量——翻转后对结论影响最大的假设：

```
⚡ 关键变量：H2 [假设描述] — 若翻转则 [影响描述]
```

每条产品线的三情景分析中，至少标注 1 个关键变量。关键变量应与 [[observable-indicators]] 绑定，使其可被持续跟踪。

### E. 示例

以某光模块公司 800G 产品线为例：

```
原子假设分解：
H1 [FACT]    北美云厂商 2025 年 Capex 指引同比+30%（来源：Meta/Google 最新财报）      置信度：高
H2 [ASSUMPTION] 800G 光模块在数据中心部署渗透率从 15% 提升至 40%（来源：LightCounting 预测）  置信度：中
H3 [ASSUMPTION] 公司 800G 市占率维持 25%（来源：公司投资者交流纪要）                    置信度：中
H4 [PREDICTION] 公司 800G 产品线营收同比+120%                                     置信度：中

因果链：
H1 [云厂商Capex+30%] →【资本开支中约40%用于网络设备，800G是主力升级方向 | 强 | 当季】→ H2 [渗透率15%→40%]
H2 [渗透率提升] →【行业总需求扩大，份额稳定条件下订单同步增长 | 中 | 1-2季度】→ H4 [营收+120%]
H3 [市占率25%] →【取决于良率、交付能力、客户认证进度 | 中 | 持续】→ H4 [营收+120%]

偏误自检：
- B2 锚定效应：+120% 增速并非简单外推历史，而是从渗透率曲线推导，但 H2 的 40% 渗透率本身依赖 LightCounting 预测，需交叉验证
- B7 生态谬误：行业增速不等于公司增速，H3 市占率假设是独立变量，需单独跟踪

⚡ 关键变量：H2 [800G渗透率达40%] — 若渗透率仅达25%，营收增速将从+120%降至约+60%
⚡ 关键变量：H3 [市占率维持25%] — 若因竞争被压缩至15%，营收增速将进一步打折至约+35%
```
