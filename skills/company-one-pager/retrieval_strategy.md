# 公司一页纸检索策略

**文档版本**: v1.0（适配 Claude Code，原 AE 版本 v1.0）
**用途**: 各 Section 的检索查询模板、时间范围和数据来源指引

## 工具说明

| 原 Alpha Engine 工具 | Claude Code 替代 |
|---|---|
| `search_finance_reports` | `web_search` + `web_fetch` |
| `query_finance_data` | `fetch_financials.py`（akshare） |
| `ask_web_question` | `web_search` + `web_fetch` |

**原参数转换规则：**
- `date_range`：转为查询语句中的时间修饰词（如"近三个月"、"2025年"）
- `doc_type: report`：在查询中补充"券商研报 机构报告"提示词
- `doc_type: foreign_report`：在查询中补充"Goldman Sachs Morgan Stanley JPMorgan 外资投行"
- `recall_num`：不适用，改为用 `web_fetch` 深入读取最相关的 2-3 个页面

## 搜索优化建议

1. **优先来源**：东方财富（eastmoney.com）、同花顺（10jqka.com.cn）、雪球（xueqiu.com）
2. **研报来源**：用 `web_fetch` 深入读取搜索结果中的研报页面
3. **数据缺失**：用"-"填充，不编造数据
4. **时间敏感查询**：在查询词中加入具体年份（如"2025年"）提高精度
