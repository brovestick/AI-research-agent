# User Query Formatting Template


## Purpose

  

Transform the user's topic stock picking request into a structured research question

with clear output requirements.

  

## Research Question Format

  

Analyze the theme "{topic}" and identify closely associated listed companies.

The final output must include:

  

### 1. Theme Overview (1200-1500 words)

  

A comprehensive analysis covering:

- Core thesis (concise investment value statement)

- Key drivers (policy, technology breakthroughs, demand surge)

- Industry chain deep dive (upstream, midstream, downstream — list key companies for each segment)

- Market size and value flow direction

- Application scenarios

- Future trends

- Valuation and investment themes

  

### 2. Industry Chain Diagram (1-3 charts)

  

Mermaid flowchart(s) showing:

- Core segments of the industry chain

- Representative companies at each node

- Capital/value flow directions

- For simple chains (≤20 nodes): 1 comprehensive diagram

- For complex chains (>20 nodes): split into 2-3 focused diagrams

  

### 3. Core Stock Selection Table

  

A table of 30-40 companies with high thematic relevance:

  

| Column | Description |

|--------|-------------|

| 公司代码 | Stock code (e.g., 600519.SH, 300750.SZ, 09880.HK) |

| 公司名称 | Company name |

| 核心产业环节 | Industry segment (upstream materials, midstream manufacturing, downstream applications, infrastructure) |

| 关联方式 | Association type: core business/product, supply chain collaboration, capital/equity linkage, technology/patent |

| 入选理由 | Selection rationale with data support (1-3 bullet points): revenue share, market share, growth rate, order pipeline |

| 受益程度 | Benefit level (★☆☆☆☆ to ★★★★★) |

  

## Analysis Requirements

  

- **Data-driven**: All selection rationales must cite verifiable data (financial reports, industry reports, announcements)

- **Global coverage**: Search for A-share, HK-listed, and US-listed companies

- **Exclude false associations**: Filter out companies with only conceptual ties, minimal equity stakes, or negligible business relevance

- **Quantitative support**: Association type and benefit level must have direct, quantifiable logic

  

## Planning Requirements

  

Generate 4 plans for execution:

- Plans 1-3: Parallel search plans (no dependencies between them)

- Plan 4: Integration and report generation plan

  

The first 3 plans are for data retrieval only; only Plan 4 handles synthesis and output.
