# 一页纸

> 来源：`skills/company-one-pager/` | 状态：已上线

## 概述

一页纸决策备忘录工作流，面向忙碌的基金经理，产出一份可在 20 秒内快速上手的个股决策参考。5 个 Section 严格串行执行，每个 Section 完成"检索 → 分析 → 输出"完整闭环后再进入下一个。

## 工作流结构

```
S1 公司近况 ──→ S2 核心投资逻辑 ──→ S3 未来事件与跟踪指标 ──→ S4 业务拆分 ──→ S5 财务与估值快照
  2 queries       5 queries            3 queries               4 queries       4-6 queries
```

每个 Section 内部流程：检索（web_search + web_fetch）→ 分析 → 按 `output_format.md` 输出。

## Section 详情

### S1：公司近况

| 项目 | 说明 |
|------|------|
| 查询数 | 2 |
| 时间范围 | 近 3 个月 |
| 输出格式 | 单段散文：3 个月内事件（股价异动、财报、产品、战略） |
| 检索要点 | 近期股价异动 + 最新公告/重大事件 |

**引用的知识节点：**
- [[data-timeliness]] — 确保引用最近 3 个月数据

### S2：核心投资逻辑

| 项目 | 说明 |
|------|------|
| 查询数 | 5 |
| 时间范围 | 3 个月 ~ 1 年 |
| 输出格式 | 三个子节：短期逻辑 / 长期逻辑 / 风险提示，各 3-5 个 bullet，纯数据驱动 |
| 检索要点 | 股价驱动因子、短期逻辑、长期逻辑、管理层指引、核心风险 |

**引用的知识节点：**
- [[cyclical-vs-growth]] — 短期 vs 长期逻辑的周期/成长属性判断
- [[bull-bear-divergence]] — 多空逻辑与风险因子梳理

### S3：未来事件与核心跟踪指标

| 项目 | 说明 |
|------|------|
| 查询数 | 3 |
| 时间范围 | 6 个月 ~ 1 年 |
| 输出格式 | 催化剂表（1-3 月 / 3-6 月）+ 跟踪指标表（短期 2-3 项 + 长期 2-3 项） |
| 检索要点 | 近期催化剂、中期催化剂、核心跟踪指标 |

**引用的知识节点：**
- [[catalyst-format]] — 催化剂表格格式（时间、事件、市场预期）
- [[observable-indicators]] — 核心跟踪指标的选取与绑定

### S4：业务拆分

| 项目 | 说明 |
|------|------|
| 查询数 | 4 |
| 时间范围 | 3 个月 ~ 1 年 |
| 输出格式 | 盈利模式（2-3 条收入流）、市场地位（量化竞争定位段落）、业务单元 bullet、最新业绩分部表 |
| 检索要点 | 盈利模式、市占率/定位、分部业绩、最新财报分部数据 |

**引用的知识节点：**
- [[product-line-breakdown]] — 产品线收入与毛利拆分
- [[competitive-landscape]] — 市场份额与竞争定位
- [[value-chain-bargaining]] — 产业链定位与议价力
- [[pricing-power]] — 定价权与成本传导能力

### S5：财务与估值快照

| 项目 | 说明 |
|------|------|
| 查询数 | 4-6（含 `fetch_financials.py`） |
| 时间范围 | 3 个月 ~ 1 年 |
| 输出格式 | 最新财报点评（2-3 bullet）+ 三张表（历史/预测财务、多机构一致预期、可比公司估值） |
| 检索要点 | 最新财报解读、历史+预测数据、国内券商一致预期、外资投行一致预期、可比公司估值 |
| 工具 | 优先 `fetch_financials.py` 获取结构化财务数据 |

**引用的知识节点：**
- [[financial-metrics-table]] — 财务指标体系与表格结构
- [[valuation-assessment]] — 估值方法与可比公司选择
- [[three-scenario-assumption]] — 预测数据的情景区分（如适用）
- [[causal-chain-reasoning]] — 预测数据须标注关键因果依赖

## 数据来源优先级

1. **主要**：东方财富（eastmoney.com）、同花顺（10jqka.com.cn）、雪球（xueqiu.com）
2. **研报**：通过 `web_fetch` 深度阅读券商研究页面
3. **缺失处理**：用 `-` 填充，禁止编造

## 适用的通用约定

全部 5 个 conventions 适用：

- [[data-sourcing]] — 数据来源优先级与标注
- [[data-timeliness]] — 时效性要求与过期提示
- [[uncertainty-labeling]] — 不确定性标注规范
- [[web-search-priority]] — 联网检索优先原则
- [[observable-indicators]] — 可观测指标绑定

## 与其他工作流的关系

- **research-report**：一页纸是研报的精简版，适合快速决策；深度分析仍需完整研报
- **due-diligence**：可先做尽调发掘核心问题，再出一页纸呈现结论
