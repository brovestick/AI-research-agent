登记材料 $ARGUMENTS

参数格式：公司代码_简称 + 材料类型（年报/研报/公告/纪要）

---

## 前置条件

公司目录 `companies/{代码}_{简称}/` 已存在，原始文件已放入 `raw/{类别}/`：
- 年报/半年报/季报 → `raw/annual_reports/`
- 券商研报 → `raw/broker_reports/`
- 招股书、定增公告 → `raw/announcements/`
- 投资者关系纪要 → `raw/IR/`

---

## 处理流程

### 1. 定位公司目录

```
companies/{代码}_{简称}/
```

确认 `raw/` 下存在用户指定类别的 PDF 文件。**跳过文件名以 `（已处理）` 开头的文件**——这些文件已经登记过，无需重复处理。

### 2. 按材料类型处理

#### 年报/半年报

对 `raw/annual_reports/` 中的每份 PDF：

```bash
cd research_agent && /opt/anaconda3/bin/python3 tools/annrpt_extract.py "<pdf_path>"
```

`annrpt_extract.py` 自动提取第二节+第三节+财务主表。输出为结构化文本。

**立刻** 将提取结果写入 `processed/annual_reports/{原始文件主题}.md`：
- Front matter: date, type, period, source
- 正文按以下维度组织：
  1. 收入结构变化
  2. 毛利率驱动因素
  3. 期间费用分析
  4. 现金流与资产负债定性分析
  5. 产销量与产能利用率
  6. 市场竞争态势
  7. 订单与需求前瞻
  8. 研发与新业态动态
  9. 管理层前瞻性表述
  10. 参股控股公司情况
  11. 风险与不确定性
  12. 结构化财务数据（损益类 + 现金流类 + 资产负债类 + 应收账龄）

**⚠️ 严禁额外提取：`annrpt_extract.py` 的产出即为全部数据源，不得再调用 `pdf_extract.py` 补提任何页面。某个维度在提取结果中找不到对应内容时，如实填写"材料中缺失此内容"，禁止编造。**

#### 券商研报

对 `raw/broker_reports/` 中的每份 PDF：

```bash
/opt/anaconda3/bin/python3 tools/pdf_extract.py "<pdf_path>"
```

提取核心观点、盈利预测、目标价、评级，写入 `processed/broker_reports/{原始文件主题}.md`。

#### 招股书/公告

对 `raw/announcements/` 中的每份 PDF：

```bash
/opt/anaconda3/bin/python3 tools/pdf_extract.py "<pdf_path>"
```

提取重大事项、业务描述、融资用途，写入 `processed/announcements/{原始文件主题}.md`。

#### 投资者关系纪要

对 `raw/IR/` 中的每份文件：

直接 Read 或 `pdf_extract.py` 提取，写入 `processed/IR/{原始文件主题}.md`。

---

## 执行纪律

遵循 CLAUDE.md 中的**流式思考+流式写入**规则：

1. `annrpt_extract.py` 跑完后，**立刻** Write 骨架文件，不做任何额外提取
2. **严禁调用 `pdf_extract.py` 对年报做额外页面提取**——`annrpt_extract.py` 的产出即为唯一数据源
3. 逐维度填充：直接基于提取结果 Edit 写入，某维度内容缺失则填写"材料中缺失此内容"，禁止编造
4. 多文件串行：一份材料完整处理完再开始下一份

---

## 命名规则

产出文件名：`{原始文件主题}.md`（如 `2024年年度报告.md`），不加日期前缀。

所有数字和结论必须使用溯源标记：【来源：文件名，页码/表格】

## 完成标记

每份材料登记完成后，将原始 PDF 文件重命名，在文件名前添加 `（已处理）` 前缀：

```bash
mv "<原路径>/<原文件名>" "<原路径>/（已处理）<原文件名>"
```

例如：`2025-04-03：振江股份：振江股份2024年年度报告.pdf` → `（已处理）2025-04-03：振江股份：振江股份2024年年度报告.pdf`

这样下次对同一目录执行 `/登记材料` 时会自动跳过已处理的文件。
