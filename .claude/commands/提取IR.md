提取IR $ARGUMENTS

参数格式：公司简称（如 斯瑞新材）

---

## 前置条件

公司目录 `companies/{代码}_{简称}/` 已存在，`raw/IR/` 中已放入至少一份投资者关系活动记录 `.docx` 文件。

---

## 处理流程

### 1. 定位公司目录

在 `companies/` 下查找包含参数简称的目录：

```bash
ls -d companies/*_{简称}
```

确认匹配到唯一目录，且 `raw/IR/` 存在并包含 `.docx` 文件。

### 2. 执行提取

```bash
cd research_agent && /opt/anaconda3/bin/python3 tools/extract_IR.py --company "companies/{匹配到的目录名}"
```

脚本会逐个处理 `raw/IR/` 下的 `.docx` 文件：
1. 读取 `.docx` 中的表格内容
2. 提取 `投资者关系活动主要内容介绍` 和 `日期` 字段
3. 输出结构化 Markdown 到 `processed/IR/{文件名}.md`
4. 将原文件重命名为 `(已处理){文件名}.docx`

### 3. 输出结果

处理完成后汇报：
- 成功处理的文件数量及列表
- 跳过的文件列表（已处理）
- 失败的文件列表（如有）

---

## 执行纪律

1. **一条命令完成**：直接调用 `extract_IR.py --company`，脚本内部处理扫描、提取、重命名
2. **不做额外处理**：脚本产出即为最终结果，不需要二次加工
3. **串行处理**：脚本内部已保证逐文件串行

---
