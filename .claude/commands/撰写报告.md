撰写报告 $ARGUMENTS

参数格式：公司代码_简称（如 688102_斯瑞新材）

---

## 前置条件

1. `companies/{代码}_{简称}/user_data.xlsx` 已填写 `company` 和 `code`（其余字段可选，也兼容 .csv）
2. `companies/{代码}_{简称}/processed/annual_reports/` 已有年报 MD（先执行 /登记材料）
3. `companies/{代码}_{简称}/financial_data/` 已放入 iFinD 导出的 XLSX

---

## 执行步骤

### 1. 初始化

```bash
cd research_agent && /opt/anaconda3/bin/python3 main.py native init --company-dir "companies/$ARGUMENTS"
```

从输出中获取 `RUN_ID`。

### 2. 构建模块 01

```bash
/opt/anaconda3/bin/python3 main.py native build --run-id {run_id} --module 01
```

### 3. 模块 01（子进程）

使用 Agent 子进程执行：
- Read prompt 文件
- 用 mcp__WebSearch__bailian_web_search 联网搜索补充信息
- 撰写 Markdown 回答，用 heredoc 写入 ANSWER_PATH
- 执行 apply + build 02

### 4. 模块 02（子进程）

同上，Agent 子进程执行模块 02，完成后 apply + build 03。

### 5. 模块 03（主 context）

在主 context 中直接执行：
- Read prompt 文件
- 撰写财务分析回答
- Apply 后展示 financial_review.md
- **等待用户精确回复 `approve`**

### 6. 模块 04-06（主 context）

用户 approve 后，依次在主 context 中执行模块 04、05、06。

### 7. 生成产出

```bash
/opt/anaconda3/bin/python3 main.py native finalize --run-id {run_id}
```

产出写入公司目录：
- `companies/{代码}_{简称}/report.md`
- `companies/{代码}_{简称}/估值模板.xlsx`

---

## 执行规则

- 模块 01、02 通过 Agent 子进程隔离 context，prompt 全文不进入主 context
- 模块 03 需要审批交互，在主 context 直接执行
- 模块 04-06 prompt 较轻，在主 context 直接执行
- 严格按 CLAUDE.md 中的状态机铁律和 Session 分段规则执行
- 每一步以 `run_state.json` 为准，不依赖对话历史
